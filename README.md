# ANV-Ai

Одностраничный статический сайт ANV-Ai. GitHub Pages обслуживает `main / (root)`: https://smit1980.github.io/anv-ai/. Сборка и npm-пакеты не нужны.

## Запуск и проверка

`python -m http.server 48766 --bind 127.0.0.1` из корня проекта, затем http://127.0.0.1:48766/.

- `node --check js/main.js` и `node --check js/sculpture.js` — синтаксис.
- `python tools/check-site.py` — ссылки, файлы, SVG, метаданные.
- `node --test tests/motion.test.cjs` — reduced motion, мобильный режим, пауза, остановка вне экрана, fallback.
- Перед публикацией проверить сценарии, мобильное меню и форму в браузере. После `git push origin main` дождаться Pages и проверить внешний адрес.

## Контакт

Форма не отправляет данные на сервер и не сохраняет их в localStorage. Имя, роль и задача обязательны; компания необязательна. После проверки появляется черновик: можно копировать, вернуться к редактированию и самостоятельно отправить в Telegram. Ссылка контакта сохранена: `https://t.me/SmitAnin`.

Три вкладки показывают иллюстративные сценарии, а не результаты клиентов. Кнопки сценариев и форматов переносят выбранную задачу в форму.

## Визуальные ресурсы

- Manrope (400/600/800) + IBM Plex Mono (400), кириллица, локальные TTF из Google Fonts. SIL OFL сохранены в `assets/licenses/`. Нет запросов к шрифтовому CDN при посещении сайта.
- Lucide через Iconify: локальный SVG-спрайт, полный ISC/MIT notice сохранён в `assets/licenses/lucide-LICENSE.txt`. Файлы отдельных иконок — источники для пересборки спрайта.
- Палитра: тёплый графит `#202522`, бумага `#f4f3ed`, персик `#f6a77a`, шалфей `#d9e1d0`. Роли и состояния задаются CSS-переменными.
- 21st.dev и Sigma изучены как референсы взаимодействий и системности. Их компоненты и платные материалы не скопированы; React/shadcn не подключены.
- Авторская trefoil-скульптура: Canvas2D-проекция 3D-кривой, без WebGL и библиотек. Статичный SVG — fallback. Анимация 30 кадров/с с ограничением DPR, паузой, остановкой вне экрана, на мобильных и при `prefers-reduced-motion`.
- Знак бренда, графика и PNG Open Graph-обложка созданы в этом проекте. `python tools/build-assets.py` пересобирает SVG и OG; helper требует Pillow, самому сайту он не нужен.
- В проекте нет трекеров, внешних скриптов и изображений. Без JavaScript остаются контент, раскрытые сценарии, навигация и прямой контакт Telegram.

Исследование 14 источников и ограничения: [docs/design-resources.md](docs/design-resources.md). Фактически применённые ресурсы указаны выше; рекомендуемая в исследовании WOFF2-доставка заменена локальными TTF без дополнительных инструментов сборки.
