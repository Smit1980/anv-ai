# ANV-Ai

Одностраничный статический сайт ANV-Ai. Сборка не требуется: GitHub Pages обслуживает корневой `index.html`.

## Контакт

Форма не отправляет данные на сервер. После валидации она показывает черновик обращения; посетитель копирует его и отправляет через Telegram самостоятельно.

## Визуальные ресурсы

- `IBM Plex Sans` и `IBM Plex Mono` загружаются из Google Fonts; обе семьи распространяются по SIL Open Font License.
- Иконка и Open Graph-обложка созданы в этом репозитории.
- В проекте нет сторонних изображений, 3D-моделей, видео или трекеров.
